# YWI Board Votes

Board voting between meetings for the Yuba Watershed Institute: magic-link sign-in restricted to the
board roster, motions that are drafted, moved, seconded, and voted on by the people doing it, and a
written-consent PDF for the minutes file.

Live: https://ywi-board-vote.vercel.app

Stack: Next.js 15 (App Router, server actions), Postgres on Neon, Resend for sign-in email, pdf-lib.
Deployed on Vercel. See SETUP.md for setup, operations, and the legal reasoning behind the PDF wording.
